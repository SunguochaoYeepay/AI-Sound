# 环境音功能说明

## 功能概述

AI-Sound平台提供两个相关的环境音功能，它们有不同的职责和工作流程：

## 1. 环境音分析 (`/environment-sounds`)

### 🎯 功能职责
- **环境音分析和管理**
- 分析书籍内容，识别需要环境音的场景
- 生成环境音轨道配置
- 管理环境音生成项目

### 🔄 工作流程
1. **创建分析项目** - 选择书籍，创建环境音分析项目
2. **内容分析** - AI分析书籍内容，识别环境音需求
3. **轨道配置** - 生成环境音轨道配置（关键词、时长、强度等）
4. **音频生成** - 调用TangoFlux AI生成环境音文件
5. **项目管理** - 管理分析结果和生成的音频文件

### 📁 相关文件
- `EnvironmentSounds.vue` - 主页面
- `EnvironmentAnalysis.vue` - 分析页面
- `EnvironmentAnalysisDetail.vue` - 分析详情页面
- `environment_generation_router.py` - 后端API

## 2. 环境音混合 (`/environment-mixing`)

### 🎯 功能职责
- **环境音混合和编辑**
- 将生成的环境音与对话音频混合
- 创建最终的沉浸式音频作品
- 提供混音编辑功能

### 🔄 工作流程
1. **选择项目** - 选择已完成环境音分析的项目
2. **配置混音** - 设置混音参数（音量、淡入淡出等）
3. **音频混合** - 将对话音频与环境音混合
4. **编辑调整** - 提供混音编辑和调整功能
5. **导出作品** - 导出最终的混合音频文件

### 📁 相关文件
- `EnvironmentMixing.vue` - 主页面
- `EnvironmentMixingAnalysisDrawer.vue` - 混音配置抽屉
- `EnvironmentMixingEditDrawer.vue` - 混音编辑抽屉
- `environment_mixing_router.py` - 后端API

## 功能关系图

```
📚 书籍内容
    ↓
🔍 环境音分析 (/environment-sounds)
    ↓
🎵 生成环境音文件
    ↓
🎛️ 环境音混合 (/environment-mixing)
    ↓
🎬 最终混音作品
```

## 菜单配置

### 左侧菜单结构
```
🎵 环境音制作 (子菜单)
├── 1️⃣ 环境音分析 - 对应 `/environment-sounds` 路由
└── 2️⃣ 环境音混合 - 对应 `/environment-mixing` 路由
```

### 页面标题
- 环境音分析页面：`环境音分析`
- 环境音混合页面：`环境音混合`

### 菜单设计理念
- **分组管理**：将相关功能放在同一个子菜单下，避免菜单项过多
- **步骤标识**：使用数字emoji (1️⃣ 2️⃣) 明确表示工作流程顺序
- **功能区分**：通过子菜单结构清晰区分两个不同但相关的功能

## 使用建议

1. **首次使用**：先使用"环境音分析"功能分析书籍内容并生成环境音
2. **后续处理**：使用"环境音混合"功能将环境音与对话音频混合
3. **工作流程**：环境音分析 → 环境音混合 → 最终作品

## 技术架构

### 前端架构
- Vue 3 + Ant Design Vue
- 响应式设计，支持移动端
- WebSocket实时通信

### 后端架构
- FastAPI + SQLAlchemy
- TangoFlux AI音频生成
- MoviePy音频处理
- PostgreSQL数据存储

### 数据流
1. 书籍内容 → 环境音分析 → 轨道配置
2. 轨道配置 → TangoFlux → 环境音文件
3. 环境音文件 + 对话音频 → 混音处理 → 最终作品
