# 音频分镜卡设计文档 v2.0

## 🎯 核心目标

基于**段落级6卡分析**，通过**章节级段落整合**，生成完整的音频分镜卡。段落剧本与其他卡完全基于段落分析，章节剧本就是做各个段落的整合，这样时间计算更好控制。

## 🏗️ 系统架构

### 数据流向
```
段落文本 → 段落级分析 → 段落剧本 + 6卡分析 → 章节整合 → 音频分镜卡
```

### 核心组件
1. **段落分析器**：为每个段落生成完整的6卡分析（已完成）
2. **段落剧本生成器**：基于段落分析生成专注人说话的段落剧本
3. **章节整合器**：整合所有段落的分析结果，生成章节级数据
4. **音频分镜生成器**：基于整合结果生成最终的音频分镜卡

## 🎭 段落级分析架构

### 设计说明
**为什么使用 synthesis_json 格式？**
- **与智能准备完全兼容**：段落级分析输出与书籍智能准备格式100%一致
- **与合成中心兼容**：合成中心可以直接使用 synthesis_plan 进行音频合成
- **数据格式统一**：整个系统使用统一的数据结构，避免转换步骤
- **直接可用**：段落分析结果可以直接用于音频合成，无需额外处理

**段落剧本的定义**
- **段落剧本**：就是 `synthesis_json` 部分，专注人声合成（对话+旁白）
- **6卡分析**：为段落剧本提供智能化的TTS参数和音频配置
- **两者结合**：形成完整的段落级音频制作方案

### TTS参数自动生成算法

#### 核心生成函数
```python
def generateTTSParams(sixCardAnalysis):
    """基于6卡分析自动生成TTS参数"""
    
    # 基础参数（默认值）
    baseParams = {
        "timeStep": 32,
        "pWeight": 1.4,
        "tWeight": 3.0,
        "dur_alpha": 1.0,
        "dur_disturb": 0.1
    }
    
    # 1. 角色权重计算
    if sixCardAnalysis.character_card:
        characterWeight = getCharacterWeight(sixCardAnalysis.character_card)
        baseParams["timeStep"] += characterWeight["timeStepBonus"]
        baseParams["pWeight"] += characterWeight["pWeightBonus"]
        baseParams["tWeight"] += characterWeight["tWeightBonus"]
    
    # 2. 情绪权重计算
    if sixCardAnalysis.emotion_card:
        emotionWeight = getEmotionWeight(sixCardAnalysis.emotion_card)
        baseParams["dur_alpha"] *= emotionWeight["durAlphaMultiplier"]
        baseParams["dur_disturb"] += emotionWeight["durDisturbBonus"]
        baseParams["pWeight"] += emotionWeight["pWeightBonus"]
    
    # 3. 事件权重计算
    if sixCardAnalysis.event_card:
        eventWeight = getEventWeight(sixCardAnalysis.event_card)
        baseParams["timeStep"] += eventWeight["timeStepBonus"]
        baseParams["pWeight"] += eventWeight["pWeightBonus"]
        baseParams["tWeight"] += eventWeight["tWeightBonus"]
    
    # 4. 场景权重计算
    if sixCardAnalysis.scene_card:
        sceneWeight = getSceneWeight(sixCardAnalysis.scene_card)
        baseParams["pWeight"] += sceneWeight["pWeightBonus"]
        baseParams["dur_alpha"] *= sceneWeight["durAlphaMultiplier"]
    
    # 5. 参数范围限制
    baseParams["timeStep"] = max(20, min(50, baseParams["timeStep"]))
    baseParams["pWeight"] = max(1.0, min(2.0, baseParams["pWeight"]))
    baseParams["tWeight"] = max(2.0, min(4.0, baseParams["tWeight"]))
    baseParams["dur_alpha"] = max(0.5, min(2.0, baseParams["dur_alpha"]))
    baseParams["dur_disturb"] = max(0.0, min(0.3, baseParams["dur_disturb"]))
    
    return baseParams
```

#### 权重计算函数
```python
def getCharacterWeight(characterCard):
    """计算角色权重"""
    roleType = characterCard["characters_involved"][0]["role_type"]
    
    if roleType == "主角":
        return {
            "timeStepBonus": 3,
            "pWeightBonus": 0.2,
            "tWeightBonus": 0.2
        }
    elif roleType == "重要配角":
        return {
            "timeStepBonus": 0,
            "pWeightBonus": 0.1,
            "tWeightBonus": 0.0
        }
    elif roleType == "一般配角":
        return {
            "timeStepBonus": -4,
            "pWeightBonus": -0.1,
            "tWeightBonus": -0.2
        }
    else:  # 群众
        return {
            "timeStepBonus": -7,
            "pWeightBonus": -0.2,
            "tWeightBonus": -0.5
        }

def getEmotionWeight(emotionCard):
    """计算情绪权重"""
    primaryEmotion = emotionCard["character_emotions"].get("当前角色", "平静")
    intensity = emotionCard.get("emotional_intensity", 5)
    
    emotionRules = EMOTION_TTS_RULES.get(primaryEmotion, {})
    intensityMultiplier = intensity / 10.0  # 1-10强度归一化
    
    return {
        "durAlphaMultiplier": emotionRules.get("dur_alpha", 1.0),
        "durDisturbBonus": emotionRules.get("dur_disturb", 0.0) * intensityMultiplier,
        "pWeightBonus": emotionRules.get("pWeight", 0.0) * intensityMultiplier
    }
```

## ⏱️ 时间计算策略

### 段落级时间计算
```
旁白时长 = 旁白字数 × 旁白语速系数（200字/分钟）
对话时长 = 对话字数 × 角色语速系数（180-220字/分钟）× 情绪调整系数
段落总时长 = Σ(所有旁白时长 + 所有对话时长)
```

### 情绪调整系数
- **愤怒**：+20%（语速加快）
- **悲伤**：-15%（语速放慢）
- **紧张**：+10%（语速略快）
- **平静**：±0%（标准语速）

### 章节级时间整合
```
章节总时长 = Σ(所有段落时长)
段落在章节中的绝对时间 = 前面所有段落时长累加 + 段落内相对时间
```

## 🔄 章节整合逻辑

### 核心整合函数
```python
def integrate_chapter_from_paragraphs(paragraphs_data):
    # 1. 时间轴整合（累加段落时间）
    chapter_timeline = []
    current_time = 0
    
    for paragraph in paragraphs_data:
        # 段落内时间转换为章节时间
        for segment in paragraph["synthesis_json"]["synthesis_plan"]:
            segment["start_time"] += current_time
            segment["end_time"] += current_time
            segment["paragraph_id"] = paragraph["paragraph_id"]
            chapter_timeline.append(segment)
        
        # 累加段落总时长
        paragraph_duration = calculate_paragraph_duration(paragraph)
        current_time += paragraph_duration
    
    # 2. 角色信息去重合并
    all_characters = {}
    for paragraph in paragraphs_data:
        for segment in paragraph["synthesis_json"]["synthesis_plan"]:
            char_name = segment["speaker"]
            if char_name not in all_characters:
                all_characters[char_name] = {
                    "name": char_name,
                    "character_id": segment["character_id"],
                    "voice_name": segment["voice_name"],
                    "appearances": []
                }
            all_characters[char_name]["appearances"].append({
                "paragraph_id": paragraph["paragraph_id"],
                "start_time": segment["start_time"],
                "end_time": segment["end_time"],
                "text": segment["text"]
            })
    
    # 3. 场景信息按段落顺序排列
    scene_sequence = []
    for paragraph in paragraphs_data:
        if paragraph["scene_card"]:
            scene_sequence.append({
                "paragraph_id": paragraph["paragraph_id"],
                "scene_info": paragraph["scene_card"],
                "start_time": get_paragraph_start_time(paragraph, chapter_timeline),
                "end_time": get_paragraph_end_time(paragraph, chapter_timeline)
            })
    
    # 4. 音频配置整合
    audio_config = integrate_audio_config(paragraphs_data)
    
    return {
        "chapter_timeline": chapter_timeline,
        "characters": list(all_characters.values()),
        "scene_sequence": scene_sequence,
        "audio_config": audio_config,
        "total_duration": current_time
    }
```

### 音频配置整合
```python
def integrate_audio_config(paragraphs_data):
    # 收集所有段落的音频配置
    all_background_music = []
    all_sound_effects = []
    all_mixing_params = []
    
    for paragraph in paragraphs_data:
        audio_card = paragraph["audio_storyboard_card"]
        
        # 背景音乐
        if audio_card["background_music"]:
            all_background_music.append({
                "paragraph_id": paragraph["paragraph_id"],
                "music_config": audio_card["background_music"]
            })
        
        # 音效
        for effect in audio_card["sound_effects"]:
            all_sound_effects.append({
                "paragraph_id": paragraph["paragraph_id"],
                "effect": effect
            })
        
        # 混音参数
        all_mixing_params.append(audio_card["mixing_parameters"])
    
    # 生成章节级音频配置
    return {
        "background_music": all_background_music,
        "sound_effects": all_sound_effects,
        "mixing_parameters": calculate_average_mixing_params(all_mixing_params)
    }
```

## 🎵 音轨设计

### 三种音轨结构

#### 1. 主要音轨：旁白 + 对话
- **内容来源**：段落synthesis_json.synthesis_plan中的对话和旁白内容
- **时长计算**：基于字数 × 语速系数
- **优先级**：最高，作为音频的主要内容
- **时间轴**：来自章节整合的chapter_timeline

#### 2. 背景音乐音轨
- **内容来源**：各段落的audio_storyboard_card.background_music
- **音量控制**：通常为20-30%，不干扰主要内容
- **淡入淡出**：平滑过渡，避免突兀
- **情绪适配**：根据情节发展调整音乐风格

#### 3. 环境音音轨
- **内容来源**：各段落的scene_card.environment_sounds和audio_storyboard_card.sound_effects
- **时间点配置**：精确到秒的音效触发时间
- **音量控制**：30-40%，增强沉浸感

- **scene_sequence**：场景变化序列
  - paragraph_id：段落ID

  - start_time：开始时间
  - end_time：结束时间

## 💡 设计优势

### 1. 时间计算更好控制
- 每个段落独立计算时间，基于字数
- 章节时间 = 段落时间累加，精确可控
- 段落内时间相对，章节内时间绝对

### 2. 分析逻辑更清晰
- 段落级：专注该段落的内容分析
- 章节级：专注数据整合和时间轴合并
- 职责分离，逻辑简单

### 3. 数据一致性更好
- 段落分析结果直接使用，不重复分析
- 章节整合只是数据重组，不会产生新的不一致

### 4. 扩展性更强
- 可以单独优化段落分析
- 可以单独优化章节整合
- 模块化程度更高

### 5. 维护性更好
- 段落级问题容易定位
- 章节级问题容易隔离
- 代码结构清晰
