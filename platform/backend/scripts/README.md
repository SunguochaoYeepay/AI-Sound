# 环境音分析测试脚本

本目录包含用于测试环境音分析功能的脚本。

## 脚本列表

### 1. `test_chapter1.py`
- **功能**: 测试第一章环境音分析准确性
- **用法**: `python scripts/test_chapter1.py`
- **特点**: 专门测试第一章的10个段落，包含详细的分析报告

### 2. `test_llm.py`
- **功能**: 简单测试LLM分析功能
- **用法**: `python scripts/test_llm.py`
- **特点**: 直接测试LLM的时序分析能力，不依赖完整的分析器

### 3. `test_all.py`
- **功能**: 通用环境音分析测试脚本
- **用法**: 
  - 测试所有章节: `python scripts/test_all.py`
  - 测试特定章节: `python scripts/test_all.py 第一章`
- **特点**: 
  - 支持测试多个预定义章节（第一章、第二章、第三章）
  - 提供汇总报告
  - 可以单独测试某个章节

## 测试数据

### 第一章测试数据
包含10个段落，涵盖：
- 脚步声
- 钟声
- 树叶声
- 摩擦声
- 油灯声
- 轻响声

### 第二章测试数据
包含5个段落，涵盖：
- 油灯声
- 噼啪声
- 脚步声
- 轻响声

### 第三章测试数据
包含5个段落，涵盖：
- 手机震动声
- 叮声
- 触控声
- 汽车引擎声
- 风声

## 测试指标

### 1. 时长准确性
- **优秀**: ≥80%
- **一般**: 60-80%
- **需要改进**: <60%

### 2. 识别数量
- **充足**: ≥3个轨道
- **一般**: 1-2个轨道
- **不足**: 0个轨道

### 3. 置信度
- **优秀**: ≥0.8
- **一般**: 0.6-0.8
- **较低**: <0.6

## 使用方法

1. **确保后端服务运行**:
   ```bash
   cd platform/backend
   python main.py
   ```

2. **运行测试脚本**:
   ```bash
   # 测试第一章
   python scripts/test_chapter1.py
   
   # 测试LLM功能
   python scripts/test_llm.py
   
   # 测试所有章节
   python scripts/test_all.py
   
   # 测试特定章节
   python scripts/test_all.py 第二章
   ```

- 关键词

### 置信度分布
按高、中、低置信度分类统计

### 总体评价
基于多个指标的综合评价

## 故障排除

### 常见问题

1. **ImportError**: 确保在正确的目录下运行脚本
2. **LLM连接失败**: 检查Ollama服务是否运行
3. **缩进错误**: 确保Python文件格式正确

### 调试建议

1. 先运行 `test_llm.py` 测试LLM连接
2. 再运行 `test_chapter1.py` 测试完整功能
3. 最后运行 `test_all.py` 进行全面测试

## 注意事项

- 测试脚本依赖Ollama服务，确保服务正常运行
- 测试结果可能因LLM模型版本而异
- 建议在修复代码后重新运行所有测试
